# Resistor Time

Source: https://developer.repebble.com/community/apps/resistor-time/

This shows the current time as a resistor with the color code matching the time of day in 24-hour time.

Configuration is done through a static HTML page hosted on github pages and some PebbleKit JS code that handles communication with the configuration page.

This only works on the Basalt color platform, as there's no point trying to show color codes on a black and white watch.
