### [Pebble.js - Pebble Package Edition!](/blog/2016/12/22/pebblejs-package.md)

[Jon Barlow](/blog/authors/jonb/) · [Freshly Baked](/blog/tags/freshly-baked/)

We're pleased to announce that [Pebble.js](https://pebble.github.io/pebblejs/)has now been [published](https://www.npmjs.com/package/pebblejs) as a[_Pebble Package_](/guides/pebble-packages.md). Pebble.js lets developers easily create Pebble applications using JavaScript by executing the JavaScript code within the mobile application on a user's phone, rather than on the watch.

### [Introducing Rocky.js Watchfaces!](/blog/2016/08/15/introducing-rockyjs-watchfaces.md)

[Jon Barlow](/blog/authors/jonb/) · [Freshly Baked](/blog/tags/freshly-baked/)

We're incredibly excited and proud to announce the first public beta version of Rocky.js watchfaces for Pebble. Rocky.js is ECMAScript 5.1 JavaScript running natively on Pebble smartwatches, thanks to[our collaboration](https://github.com/Samsung/jerryscript/wiki/JerryScriptWorkshopApril2016)with [JerryScript](https://github.com/pebble/jerryscript). This is an incredible feat of engineering!
