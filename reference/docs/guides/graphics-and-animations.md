# Graphics and Animations

Source: https://developer.repebble.com/guides/graphics-and-animations/

The Pebble SDK allows drawing of many types of graphics in apps. Using the[`Graphics Context`](/docs/c/Graphics/Graphics_Context/ "Graphics Context"), [`GBitmap`](/docs/c/Graphics/Graphics_Types/#GBitmap "GBitmap"), [`GDrawCommand`](/docs/c/Graphics/Draw_Commands/#GDrawCommand "GDrawCommand") and[`Framebuffer`](/docs/c/Graphics/Drawing_Primitives/#graphics_capture_frame_buffer "graphics\_capture\_frame\_buffer") APIs gives developers complete control over the contents of the display, and also can be used to complement UI created with the various types of [`Layer`](/docs/c/User_Interface/Layers/#Layer "Layer") available to enable more complex UI layouts.

Both image-based and property-based animations are available, as well as scheduling regular updates to UI components with [`Timer`](/docs/c/Foundation/Timer/ "Timer") objects. Creative use of [`Animation`](/docs/c/User_Interface/Animation/ "Animation") and [`PropertyAnimation`](/docs/c/User_Interface/Animation/PropertyAnimation/ "PropertyAnimation") can help to delight and engage users, as well as highlight important information inside apps.
