# Developer Connection

Source: https://developer.repebble.com/guides/tools-and-resources/developer-connection/

In order to install apps from the local SDK using the `pebble` tool, the Pebble Android or iOS app must be set up to allow a connection from the computer to the watch. This enables viewing logs and installing apps directly from the development environment, speeding up development.

Follow the steps illustrated below to get started.

## Android Instructions

In the Pebble mobile app:

- Open the overflow menu by tapping the three dot icon at the top right and tap_Settings_.

![](/assets/images/guides/publishing-tools/enable-dev-android-1.png)

- Enable the _Developer Mode_ option.

![](/assets/images/guides/publishing-tools/enable-dev-android-2.png)

- Tap _Developer Connection_ and enable the developer connection using the toggle at the top right.

![](/assets/images/guides/publishing-tools/enable-dev-android-4.png)

- Make note of the 'Server IP' and use it with the `--phone` argument.

## iOS Instructions

In the Pebble mobile app:

- Open the left-hand menu and tap the _Settings_ item.

![](/assets/images/guides/publishing-tools/enable-dev-ios-1.png)

- Enable the Developer Mode using the toggle.

![](/assets/images/guides/publishing-tools/enable-dev-ios-2.png)

- Return to the menu, then tap the _Developer_ item. Enable the Developer Connection using the toggle at the top-right.

![](/assets/images/guides/publishing-tools/enable-dev-ios-3.png)

- Make note of the 'Server IP' and use it with the `--phone` argument.
