# Pebble Packages

Source: https://developer.repebble.com/guides/pebble-packages/

It is very common to want to use some piece of common functionality that we do not provide directly in our SDK: for instance, show the weather or swap our colors in a bitmap.

To provide this functionality, developers can create _Pebble Packages_, which provide developers with easy ways to share their code.
