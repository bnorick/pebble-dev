# Pebble SDK 3.10-beta6 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.10-beta6/

_Release Date: March 4 2016_

This is a pre-release SDK, containing a preview of the new Pebble Health API.

The following release notes list only changes since [3.10-beta2](/sdk/changelogs/3.10-beta2.md).

### Changes to Firmware

- Improved Health accuracy.
- Improved firmware stability.

### Changes to SDK

- Added information necessary to debug workers as well as apps.
- Added information about SDK calls to gdb.
