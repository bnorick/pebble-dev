# Pebble SDK 3.0-beta11 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.0-beta11/

_Release Date: May 10 2015_

This is the second beta release of Pebble SDK 3.0. It includes a number of fixes to improve stability as well as new guide for Design and Interaction.

## Detailed List of Changes:

### Changes for Firmware:

- Crashes within [`worker`](/docs/c/Worker/ "Worker") will now show up with a crash dialog on the watch.
- Fixed bug where `Timeline` events displayed improper start/finish times.
- Fixed bug where images were drawn incorrectly if bounds in [`layer_set_bounds`](/docs/c/User_Interface/Layers/#layer_set_bounds "layer\_set\_bounds") were set differently than (0, 0, size.w, size.h). 

### Changes to SDK:

- Fixed a bug where apps would fail to wake up because [`Wakeup`](/docs/c/Foundation/Wakeup/ "Wakeup") expected time in UTC.
