# Pebble SDK 3.0-dp5 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.0-dp5/

_Release Date: March 27 2015_

This is the fifth Developer Preview release of Pebble SDK 3.0.

The biggest new features with this release are [antialiasing and stroke width](/guides/graphics-and-animations/drawing-primitives-images-and-text.md).

## Detailed List of Changes:

### Changes for Firmware:

- Antialiasing is enabled by default for all apps built with SDK 3.0 or higher.

### Changes to SDK:

- Added [`graphics_context_set_antialiased`](/docs/c/Graphics/Graphics_Context/#graphics_context_set_antialiased "graphics\_context\_set\_antialiased") to toggle adding antialiasing to the graphics\_draw\_\* functions. See our [Drawing Graphics](/guides/graphics-and-animations/drawing-primitives-images-and-text.md) guide for more details.
- Added [`graphics_context_set_stroke_width`](/docs/c/Graphics/Graphics_Context/#graphics_context_set_stroke_width "graphics\_context\_set\_stroke\_width") to set the stroke width for drawing routines. See our [Drawing Graphics](/guides/graphics-and-animations/drawing-primitives-images-and-text.md) guide for more details.

### Changes for SDK Tools:

- Fixed bug where projects with png-trans resources would cause build failures.

### Changes for Examples:

- Added [ks-clock-face](https://github.com/pebble-examples/ks-clock-face)example to demonstrate the new antialiasing and stroke width APIs.

### Changes for Documentation:

- Documented the [new pebble commands](/guides/tools-and-resources/pebble-tool.md) for working with the emulator, and improved the rest of the tool documentation.
