# Pebble SDK 2.9 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/2.9/

_Release Date: February 10 2015_

This release introduces actionable notifications for Android and minor stability improvements.

## Detailed List of Changes:

### Changes for Firmware:

- Add support for [Android actionable notifications](/blog/2014/12/19/Leverage-Android-Actionable-Notifications.md)
- Fix bug that caused crashes when [`mktime()`](/docs/c/Standard_C/Time/#mktime "mktime") was used 
- Fix behavior of [`window_stack_pop_all`](/docs/c/User_Interface/Window_Stack/#window_stack_pop_all "window\_stack\_pop\_all") so that only the last window is animated
- Compiler will now show an error when the resources limit is reached
- Improve the stability of [`Worker`](/docs/c/Worker/ "Worker")on launch
- Fix bug where a [`Worker`](/docs/c/Worker/ "Worker") selected from the Activity menus would not be set to default
- Fix bug where a [`Worker`](/docs/c/Worker/ "Worker") launched by a new app would not be set to default after the default worker was deleted
- Fix an issue that caused [`AppMessage`](/docs/c/Foundation/AppMessage/ "AppMessage") to report sends as failed when sending/recieving a high volume of messages
- Notification date format is standardized: "Wednesday 11, February" -\> "Wednesday, February 11"

### Changes for SDK Tools:

No changes

### Changes for Examples:

- Update openweather apis used in example apps.

### Changes for Documentation:

No changes
