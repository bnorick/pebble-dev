# Pebble SDK 4.0-dp1 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/4.0-dp1/

_Release Date: June 15 2016_

This is the first Developer Preview release of the brand new Pebble SDK 4.0. This changelog collects only changes visible to developers using the emulator. A complete changelog will be provided when 4.0 ships on physical watches.

### Changes to Firmware

- Added support for [Pebble 2](https://www.kickstarter.com/projects/597507018/pebble-2-time-2-and-core-an-entirely-new-3g-ultra).
- Added [AppGlances](/guides/user-interfaces/appglance-c.md) and Timeline ~~Peek~~ Quick View.

### Changes to SDK

- Added the new "Diorite" platform for the Pebble 2.
- Added `PBL_COMPASS`, `PBL_SMARTSTRAP_POWER`, and `PBL_PLATFORM_DIORITE`defines.
- Added [`preferred_result_display_duration`](/docs/c/User_Interface/Preferences/#preferred_result_display_duration "preferred\_result\_display\_duration") to get the recommended number of milliseconds a result window should be visible before it should closed.
- Added [`AppExitReason`](/docs/c/Foundation/Exit_Reason/#AppExitReason "AppExitReason") and [`exit_reason_set`](/docs/c/Foundation/Exit_Reason/#exit_reason_set "exit\_reason\_set")for an application to be able to notify the system of[the reason it is exiting](/guides/user-interfaces/app-exit-reason.md).
- Added [`AppGlanceSlice`](/docs/c/Foundation/App_Glance/#AppGlanceSlice "AppGlanceSlice"), [`AppGlanceResult`](/docs/c/Foundation/App_Glance/#AppGlanceResult "AppGlanceResult"), [`AppGlanceReloadSession`](/docs/c/Foundation/App_Glance/#AppGlanceReloadSession "AppGlanceReloadSession"),[`app_glance_add_slice`](/docs/c/Foundation/App_Glance/#app_glance_add_slice "app\_glance\_add\_slice"), [`AppGlanceReloadCallback`](/docs/c/Foundation/App_Glance/#AppGlanceReloadCallback "AppGlanceReloadCallback") and [`app_glance_reload`](/docs/c/Foundation/App_Glance/#app_glance_reload "app\_glance\_reload"). to support [AppGlances](/guides/user-interfaces/appglance-c.md).
- Added [Unobstructed Area APIs](/guides/user-interfaces/unobstructed-area.md):[`UnobstructedAreaWillChangeHandler`](/docs/c/User_Interface/UnobstructedArea/#UnobstructedAreaWillChangeHandler "UnobstructedAreaWillChangeHandler"),[`UnobstructedAreaChangeHandler`](/docs/c/User_Interface/UnobstructedArea/#UnobstructedAreaChangeHandler "UnobstructedAreaChangeHandler"),[`UnobstructedAreaDidChangeHandler`](/docs/c/User_Interface/UnobstructedArea/#UnobstructedAreaDidChangeHandler "UnobstructedAreaDidChangeHandler"),[`UnobstructedAreaHandlers`](/docs/c/User_Interface/UnobstructedArea/#UnobstructedAreaHandlers "UnobstructedAreaHandlers"),[`layer_get_unobstructed_bounds`](/docs/c/User_Interface/Layers/#layer_get_unobstructed_bounds "layer\_get\_unobstructed\_bounds"),[`unobstructed_area_service_subscribe`](/docs/c/User_Interface/UnobstructedArea/#unobstructed_area_service_subscribe "unobstructed\_area\_service\_subscribe")and [`unobstructed_area_service_unsubscribe`](/docs/c/User_Interface/UnobstructedArea/#unobstructed_area_service_unsubscribe "unobstructed\_area\_service\_unsubscribe")to enable a watchface to adapt to overlays partially obstructing it, such as during a Timeline ~~Peek~~ Quick View.
- Added [`HealthMetricAlert`](/docs/c/Foundation/Event_Service/HealthService/#HealthMetricAlert "HealthMetricAlert"), [`HealthAggregation`](/docs/c/Foundation/Event_Service/HealthService/#HealthAggregation "HealthAggregation"), [`health_service_peek_current_value`](/docs/c/Foundation/Event_Service/HealthService/#health_service_peek_current_value "health\_service\_peek\_current\_value"),[`health_service_peek_current_value`](/docs/c/Foundation/Event_Service/HealthService/#health_service_peek_current_value "health\_service\_peek\_current\_value"), [`health_service_aggregate_averaged`](/docs/c/Foundation/Event_Service/HealthService/#health_service_aggregate_averaged "health\_service\_aggregate\_averaged"),[`health_service_aggregate_averaged`](/docs/c/Foundation/Event_Service/HealthService/#health_service_aggregate_averaged "health\_service\_aggregate\_averaged"),[`health_service_metric_aggregate_averaged_accessible`](/docs/c/Foundation/Event_Service/HealthService/#health_service_metric_aggregate_averaged_accessible "health\_service\_metric\_aggregate\_averaged\_accessible"),[`health_service_register_metric_alert`](/docs/c/Foundation/Event_Service/HealthService/#health_service_register_metric_alert "health\_service\_register\_metric\_alert"),[`health_service_register_metric_alert`](/docs/c/Foundation/Event_Service/HealthService/#health_service_register_metric_alert "health\_service\_register\_metric\_alert") and[`health_service_cancel_metric_alert`](/docs/c/Foundation/Event_Service/HealthService/#health_service_cancel_metric_alert "health\_service\_cancel\_metric\_alert") in preparation for heart rate support. Note that these are not yet implemented.
- Report memory usage for Pebble Packages at build time.

### Known Issues

- Creating an [`AppGlanceSlice`](/docs/c/Foundation/App_Glance/#AppGlanceSlice "AppGlanceSlice") with a .expiration\_time of`APP_GLANCE_SLICE_NO_EXPIRATION_TIME` results in an AppGlanceSlice that is never displayed.
- The [`UnobstructedAreaHandlers`](/docs/c/User_Interface/UnobstructedArea/#UnobstructedAreaHandlers "UnobstructedAreaHandlers") object must be created before being passed into the [`unobstructed_area_service_subscribe`](/docs/c/User_Interface/UnobstructedArea/#unobstructed_area_service_subscribe "unobstructed\_area\_service\_subscribe") method.
- The Diorite emulator is still a little shy and will occassionally shake upon starting. If your emulator doesn't stop shaking, try installing an app - that usually brings it out of its shell.
