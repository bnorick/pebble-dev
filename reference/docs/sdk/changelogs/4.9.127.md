# Pebble SDK 4.9.127 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/4.9.127/

_Release Date: February 20 2026_

After some test releases and a lot of hard work, we're excited to announce the release of Pebble SDK 4.9.127! This release includes a number of new features and improvements, such as the new Alloy JavaScript framework, support for Pebble Round 2, and much more. We also made various bug fixes and stability improvements to ensure a better development experience.

### Changes to Firmware

- Added QEMU virtual platforms for development: `silk_flint`,`snowy_emery`, and `spalding_gabbro`.
- Added legacy app rendering mode, allowing apps compiled for older platforms to run scaled on larger displays.
- Added Arabic text shaping and right-to-left (RTL) text support, including mixed RTL-LTR text with correct justification.
- Added SpO2 support in the HRM manager.
- Added accent/highlight color settings with contrast-compatible colors.
- Added display orientation / left-handed mode support.
- Added QR code rendering support.
- Notification improvements: custom vibration patterns, timed mute options, alternative notification designs, and expanded known app icon mappings.
- Various bug fixes and stability improvements!

### Changes to SDK

- Added Alloy, a modern JavaScript framework based on the Moddable SDK, for building Pebble apps with support for the latest features and platforms.
- Ported all SDK scripts and tools to Python 3.
- Updated WAF build system to 2.1.4.
- Updated Toolchain to GCC 14 (note that this may cause some warnings in older code).
- Added `ctx.pbl_suppress_newer_gcc_warnings()` to suppress warnings in legacy code when using the new toolchain. (Add to configure in your wscript)
- Added BDF and PBF font support for resources.
- Added `moddable` project type to create apps using the Alloy framework.
- Added `Flint` and `Gabbro` platforms.
- Increased `MAX_FONT_GLYPH_SIZE` to 512 for emery and gabbro.
- Added 1% battery reporting granularity on new QEMU platforms.
- Requires `pebble-tool` ≥5.0.23.
