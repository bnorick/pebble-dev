# Pebble SDK 3.8-beta8 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.8-beta8/

_Release Date: December 2 2015_

This is a pre-release version of the Pebble SDK.

### Changes to Firmware

- Added support for Pebble Classic and Pebble Steel watches!
  - You can read more [on our blog](/blog/2015/12/02/Bringing-the-Family-Back-Together.md)
  - This is a major change! Please test your aplite apps thoroughly after rebuilding with SDK 3.8.
- Improved the rendering of [`NumberWindow`](/docs/c/User_Interface/Window/NumberWindow/ "NumberWindow").
- Fixed a race when exiting an [`ActionMenuLevel`](/docs/c/User_Interface/Window/ActionMenu/#ActionMenuLevel "ActionMenuLevel").
- Timeline pins no longer require icons, and will pick a sane default.
- Restored the double vibration when _disabling_ Quiet Time (enabling is still a single vibration).
- Resolved a memory leak in [`DictationSession`](/docs/c/Foundation/Dictation/#DictationSession "DictationSession").
- Assorted minor design changes.

### Changes to SDK

- Deprecated `png`, `pbi` and `pbi8` in favor of a new `bitmap` resource type.[Read more on our blog!](/blog/2015/12/02/Bitmap-Resources.md).
- Font resources are now somewhat smaller than they used to be.

### Changes to Pebble Tool

SDK 3.8 is the first version exclusively available via the[new pebble tool](/blog/2015/12/01/A-New-Pebble-Tool.md).

No future SDK packages will contain the tool, or any changes to the tool.

### Changes to Emulator/Phonesim

As with the pebble tool, the emulator and phone simulator are no longer coupled to the SDK.
