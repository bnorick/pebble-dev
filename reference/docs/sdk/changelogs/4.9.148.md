# Pebble SDK 4.9.148 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/4.9.148/

_Release Date: March 26 2026_

**Important:** Due to an oversight in SDK 4.9.127, all Alloy apps compiled with that version need to be recompiled with SDK 4.9.148. We apologize for the inconvenience.

### Changes to Firmware

- Added Hebrew language support, including Heebo fonts and improved right-to-left / bidirectional text rendering.
- Added support for Unicode space characters (em space, en space, non-breaking space, etc.) with correct widths and line-breaking behavior.
- Added manual time and date setting in the Settings menu, with a toggle between automatic (phone sync) and manual time sources.
- Added Back + Up button combo as a new quick launch shortcut from the watchface.
- Added deep sleep tracking display on black-and-white watches.
- Added heart rate monitoring interval setting.
- Improved display rendering: fixed bitblt overflow crash on displays wider than 255 pixels, forced display refresh on orientation changes, and fixed reversed bezel-mode animation direction.
- Removed RockyJS / JerryScript runtime support. JavaScript apps should use the Alloy (Moddable) framework introduced in SDK 4.9.127.
- Various bug fixes and stability improvements.

### Changes to SDK

- Added `RESOURCE_ID_LECO_60_NUMBERS_AM_PM` and`RESOURCE_ID_LECO_60_BOLD_NUMBERS_AM_PM` system font resources.
- Added [`kModdableCreationFlagLogInstrumentation`](/docs/c/Foundation/Alloy/#kModdableCreationFlagLogInstrumentation "kModdableCreationFlagLogInstrumentation") flag for Alloy apps to enable XS instrumentation logging. Only really needed for advanced use-cases!
- Updated Moddable (XS engine) to version 7.2.1.
