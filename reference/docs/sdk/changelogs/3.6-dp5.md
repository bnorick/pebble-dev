# Pebble SDK 3.6-dp5 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.6-dp5/

_Release Date: October 2 2015_

This changelog covers only changes since 3.6-dp2. Developer previews 3 and 4 were never shipped.

### Changes to Firmware

- Made the status bar on Chalk (Pebble Time Round) four pixels taller (from 20 to 24 pixels).
- Resolved an issue causing AppMessages to sometimes be dropped when sending both ways.
- Improved backlight behaviour when dictating text.
- Fixed a calculation error in [`grect_centered_from_polar`](/docs/c/Graphics/Drawing_Primitives/#grect_centered_from_polar "grect\_centered\_from\_polar").
- Resolved multiple issues that occured when reusing a [`DictationSession`](/docs/c/Foundation/Dictation/#DictationSession "DictationSession").

### Changes to SDK

- Added the [`GTextAttributes`](/docs/c/Graphics/Drawing_Text/#GTextAttributes "GTextAttributes") structure, with methods for defining text flow and paging on a circular display.
- Added support for [`GTextAttributes`](/docs/c/Graphics/Drawing_Text/#GTextAttributes "GTextAttributes") to [`graphics_draw_text`](/docs/c/Graphics/Drawing_Text/#graphics_draw_text "graphics\_draw\_text"). That `NULL` parameter that you've been tacking on the end for two and a half years now actually does something.
- Added methods to [`TextLayer`](/docs/c/User_Interface/Layers/TextLayer/ "TextLayer") for flowing and paging text on a circular display.
- Added paging support to [`ScrollLayer`](/docs/c/User_Interface/Layers/ScrollLayer/ "ScrollLayer").
- Improved the return codes from the dictation API.

### Changes to Pebble Tool

- Added the [`pebble transcribe` command](/guides/tools-and-resources/pebble-tool.md), enabling testing dictation in the emulator.
- Added the [`pebble data-logging` command](/guides/tools-and-resources/pebble-tool.md), to download stored datalogging from the watch to the computer.

### Changes to Emulator/Phonesim

- Added a translucent ring around the inside of the emulator to remind you of masked pixels.
- Resolved an issue causing appmessage events to fire repeatedly.
- Resolved an issue causing app installs to frequently fail on Linux.
- Resolved an issue causing emulated Bluetooth to be broadly unreliable.
