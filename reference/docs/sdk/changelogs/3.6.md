# Pebble SDK 3.6 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.6/

_Release Date: October 14 2015_

This changelog contains all changes since SDK 3.4. SDK 3.5 was never shipped.

### Known Issues

- Unfocused menu layer cells on Chalk may have their content inappropriately truncated. This behavior will improve before Pebble Time Round is released.

### Changes to Firmware

- Added support for [circular watches](/round.md).
- Window stack animations were disabled on Chalk.
- Adjusted the display of [`ActionBarLayers`](/docs/c/User_Interface/Layers/ActionBarLayer/ "ActionBarLayer") for circular watches.
- Adjusted the display of [`ActionMenus`](/docs/c/User_Interface/Window/ActionMenu/ "ActionMenu") for circular watches.
- Increased the height of the [`StatusBarLayer`](/docs/c/User_Interface/Layers/StatusBarLayer/ "StatusBarLayer") on Chalk (16 to 24 pixels).
- Improved backlight behavior when dictating text.
- Added support for 8 KiB AppMessage buffers.

### Changes to SDK

- Added the new "Chalk" platform for the Pebble Time Round.
- Added the [Dictation API](/guides/pebble-apps/sensors/dictation/), enabling voice input on the Basalt and Chalk platforms.
- Added `PBL_ROUND`, `PBL_RECT` and `PBL_PLATFORM_CHALK` defines.
- Added [`PBL_IF_ROUND_ELSE`](/docs/c/Graphics/Graphics_Types/#PBL_IF_ROUND_ELSE "PBL\_IF\_ROUND\_ELSE"), [`PBL_IF_RECT_ELSE`](/docs/c/Graphics/Graphics_Types/#PBL_IF_RECT_ELSE "PBL\_IF\_RECT\_ELSE"), [`PBL_IF_COLOR_ELSE`](/docs/c/Graphics/Graphics_Types/#PBL_IF_COLOR_ELSE "PBL\_IF\_COLOR\_ELSE") and[`PBL_IF_BW_ELSE`](/docs/c/Graphics/Graphics_Types/#PBL_IF_BW_ELSE "PBL\_IF\_BW\_ELSE") macros. [`COLOR_FALLBACK`](/docs/c/Graphics/Graphics_Types/#COLOR_FALLBACK "COLOR\_FALLBACK") is now considered deprecated.
- Added [`graphics_fill_radial`](/docs/c/Graphics/Drawing_Primitives/#graphics_fill_radial "graphics\_fill\_radial") and [`graphics_draw_arc`](/docs/c/Graphics/Drawing_Primitives/#graphics_draw_arc "graphics\_draw\_arc"), for drawing partial circles.
- Added [`gpoint_from_polar`](/docs/c/Graphics/Drawing_Primitives/#gpoint_from_polar "gpoint\_from\_polar") and [`grect_centered_from_polar`](/docs/c/Graphics/Drawing_Primitives/#grect_centered_from_polar "grect\_centered\_from\_polar") for conversion from polar to cartesian coordinates.
- Added [`ContentIndicator`](/docs/c/User_Interface/Layers/ScrollLayer/#ContentIndicator "ContentIndicator"), which provides a visual indicator of content above or below the display.
- Added [`menu_layer_set_center_focused`](/docs/c/User_Interface/Layers/MenuLayer/#menu_layer_set_center_focused "menu\_layer\_set\_center\_focused"), which forces the highlighted menu item to always be in the center of the display. This is the default configuration for menus on Chalk.
- Added [`menu_layer_is_index_selected`](/docs/c/User_Interface/Layers/MenuLayer/#menu_layer_is_index_selected "menu\_layer\_is\_index\_selected").
- Added constants for the heights of menu cells on Chalk: [`MENU_CELL_ROUND_FOCUSED_SHORT_CELL_HEIGHT`](/docs/c/User_Interface/Layers/MenuLayer/#MENU_CELL_ROUND_FOCUSED_SHORT_CELL_HEIGHT "MENU\_CELL\_ROUND\_FOCUSED\_SHORT\_CELL\_HEIGHT"),[`MENU_CELL_ROUND_FOCUSED_TALL_CELL_HEIGHT`](/docs/c/User_Interface/Layers/MenuLayer/#MENU_CELL_ROUND_FOCUSED_TALL_CELL_HEIGHT "MENU\_CELL\_ROUND\_FOCUSED\_TALL\_CELL\_HEIGHT"), [`MENU_CELL_ROUND_UNFOCUSED_SHORT_CELL_HEIGHT`](/docs/c/User_Interface/Layers/MenuLayer/#MENU_CELL_ROUND_UNFOCUSED_SHORT_CELL_HEIGHT "MENU\_CELL\_ROUND\_UNFOCUSED\_SHORT\_CELL\_HEIGHT") and[`MENU_CELL_ROUND_UNFOCUSED_TALL_CELL_HEIGHT`](/docs/c/User_Interface/Layers/MenuLayer/#MENU_CELL_ROUND_UNFOCUSED_TALL_CELL_HEIGHT "MENU\_CELL\_ROUND\_UNFOCUSED\_TALL\_CELL\_HEIGHT").
- Added [`DEG_TO_TRIGANGLE`](/docs/c/Foundation/Math/#DEG_TO_TRIGANGLE "DEG\_TO\_TRIGANGLE"), the inverse of the pre-existing [`TRIGANGLE_TO_DEG`](/docs/c/Foundation/Math/#TRIGANGLE_TO_DEG "TRIGANGLE\_TO\_DEG").
- Added [`GBitmapFormat8BitCircular`](/docs/c/Graphics/Graphics_Types/#GBitmapFormat8BitCircular "GBitmapFormat8BitCircular"), the new framebuffer format used on Chalk.
- Added [`gbitmap_get_data_row_info`](/docs/c/Graphics/Graphics_Types/#gbitmap_get_data_row_info "gbitmap\_get\_data\_row\_info"), because [`GBitmapFormat8BitCircular`](/docs/c/Graphics/Graphics_Types/#GBitmapFormat8BitCircular "GBitmapFormat8BitCircular") does not have a constant number of bytes per row. This should now be used for all framebuffer manipulation.
- Added the [`GTextAttributes`](/docs/c/Graphics/Drawing_Text/#GTextAttributes "GTextAttributes") structure, with methods for defining text flow and paging on a circular display.
- Added support for [`GTextAttributes`](/docs/c/Graphics/Drawing_Text/#GTextAttributes "GTextAttributes") to [`graphics_draw_text`](/docs/c/Graphics/Drawing_Text/#graphics_draw_text "graphics\_draw\_text"). That `NULL` parameter that you've been tacking on the end for two and a half years now actually does something.
- Added methods to [`TextLayer`](/docs/c/User_Interface/Layers/TextLayer/ "TextLayer") for flowing and paging text on a circular display.
- Added paging support to [`ScrollLayer`](/docs/c/User_Interface/Layers/ScrollLayer/ "ScrollLayer").

### Changes to Pebble Tool

- Added support for Chalk and circular displays.
- Added the [`pebble transcribe` command](/guides/tools-and-resources/pebble-tool.md), enabling testing dictation in the emulator.
- Added the [`pebble data-logging` command](/guides/tools-and-resources/pebble-tool.md), to download stored datalogging from the watch to the computer.
- Added the [`pebble emu-time-format` commmand](/guides/tools-and-resources/pebble-tool.md), allowing switching of the emulator between 12-hour and 24-hour formats.

### Changes to Emulator/Phonesim

- Added support for Chalk and circular displays.
- Fixed a JavaScript runtime crash when sending non-ASCII characters by AppMessage.
