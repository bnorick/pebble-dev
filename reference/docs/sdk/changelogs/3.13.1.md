# Pebble SDK 3.13 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.13.1/

_Release Date: June 10 2016_

This is a hotfix for [SDK 3.13](/sdk/changelogs/3.13.md). This is an SDK-only release; no corresponding firmware exists.

### Changes to SDK

- Use the value of package.json's `pebble.displayName` for the app's name everywhere, instead of sometimes using `name`, which is subject to npm naming restrictions.
- When using a block AppMessage key (e.g. `Elements[6]`), the name of the base key is no longer usable directly and must be accessed numerically. This change was made to ensure that it _could_ be accessed numerically, which is the standard use-case for these array-like keys.
- Library capabilities (e.g. `location`) are now correctly merged with app capabilities.
