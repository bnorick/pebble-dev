# Pebble SDK 3.9-beta7 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/3.9-beta7/

_Release Date: January 29 2016_

This is a pre-release SDK, containing a preview of the new Pebble Health API.

The following release notes list only changes since [3.9-beta5](/sdk/changelogs/3.9-beta5.md)

### Changes to Firmware

- Fixed a crash when calling [`health_service_any_activity_accessible`](/docs/c/Foundation/Event_Service/HealthService/#health_service_any_activity_accessible "health\_service\_any\_activity\_accessible").
- Ensured that [`HealthEventSignificantUpdate`](/docs/c/Foundation/Event_Service/HealthService/#HealthEventSignificantUpdate "HealthEventSignificantUpdate") is called immediately when subscribing to the health service, as documented.
- Fixed a failure to correctly read the ambient light sensor.
- Further watchface transition tweaks.
- Improved firmware stability.
- Improved bluetooth reliability.

### Changes to SDK

- `HealthLightLevel` was renamed to [`AmbientLightLevel`](/docs/c/Foundation/Event_Service/HealthService/#AmbientLightLevel "AmbientLightLevel")
- Added `PBL_HEALTH` and `PBL_IF_HEALTH_ELSE` macros.
- Added support for multiple JavaScript files! Check out[the blog post](/blog/2016/01/29/Multiple-JavaScript-Files.md) for more details.
