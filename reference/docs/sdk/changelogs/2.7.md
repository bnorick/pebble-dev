# Pebble SDK 2.7 - Changelog

Source: https://developer.repebble.com/sdk/changelogs/2.7/

_Release Date: October 16 2014_

## Detailed List of Changes:

### Changes for Firmware:

- Add [`Wakeup`](/docs/c/Foundation/Wakeup/ "Wakeup") API
- Add [`launch_reason`](/docs/c/Foundation/Launch_Reason/#launch_reason "launch\_reason") API
- Fix a bug that caused [`watch_info_get_color`](/docs/c/Foundation/WatchInfo/#watch_info_get_color "watch\_info\_get\_color") to crash the app when used
- Add [`clock_to_timestamp`](/docs/c/Foundation/Wall_Time/#clock_to_timestamp "clock\_to\_timestamp") API
- Add [`clock_is_timezone_set`](/docs/c/Foundation/Wall_Time/#clock_is_timezone_set "clock\_is\_timezone\_set") API. In firmware 2.7, this function will always return false as timezone support is not yet implemented
- Improve Bluetooth reliability
- Fix bug showing 0% battery warning

### Changes for SDK Tools:

No changes

### Changes for Examples:

- Add [wakeup example](https://github.com/pebble-examples/feature-app-wakeup)

### Changes for Documentation:

- Add [`Wakeup`](/docs/c/Foundation/Wakeup/ "Wakeup") API documentation
- Fix bug with missing [`snprintf`](/docs/c/Standard_C/Format/#snprintf "snprintf") specifier documentation
