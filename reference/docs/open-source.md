# Pebble Open Source

Source: https://developer.repebble.com/open-source/

Here at Pebble we are big believers in the power of open source. Our firmware is [built upon FreeRTOS](/blog/2014/10/10/FreeRTOS-Modifications-From-Pebble-v2.md), and all of our mobile and web applications make use of many different open source libraries.

Whenever possible, we like to give back to the open source community, so here are just some of our open source projects available for anyone to use in their own work.

You can also check out our GitHub profile at [https://github.com/pebble/](https://github.com/pebble/).

## Pebble SDK

### [libpebble3](https://github.com/coredevices/libpebble3/)

**New for 2025!** Kotlin multiplatform library for interacting with Pebble devices. This is the modern replacement for libpebble2.

### [libpebble2](https://github.com/pebble/libpebble2/)

Library for communication with Pebble devices and emulators

### [pebble-tool](https://github.com/pebble/pebble-tool/)

The Pebble tool, as distributed in the Pebble SDK

### [pypkjs](https://github.com/pebble/pypkjs/)

Python implementation of PebbleKit JS

### [PyV8](https://github.com/pebble/pyv8/)

Pebble fork of PyV8

### [QEMU](https://github.com/pebble/qemu/)

Pebble's fork of QEMU, with support for Pebble and Pebble Time

## Node.js

### [pebble-api](https://github.com/pebble/pebble-api-node/)

Node.js client for the Pebble timeline APIs

### [koa-bunyan-logger](https://github.com/pebble/koa-bunyan-logger/)

Koa middleware for bunyan request logging

### [yieldb](https://github.com/pebble/yieldb/)

Simple, expressive and yieldable MongoDB

### [event-loop-lag](https://github.com/pebble/event-loop-lag/)

Measures Node.js event loop lag

### [joi-objectid](https://github.com/pebble/joi-objectid/)

A MongoDB ObjectId validator for Joi

### [koa-joi-router](https://github.com/pebble/koa-joi-router/)

Easy, rich and fully validated koa routing.

### [koa-resourcer](https://github.com/pebble/koa-resourcer/)

A simple resource directory mounter for koa

### [has-own](https://github.com/pebble/has-own/)

A safer .hasOwnProperty() where property name comes first: `hasOwn(name, obj)`

### [qdog](https://github.com/pebble/qdog/)

Module used for adding and reading from SQS and eventually Redis

## Other

### [Pebble.js](https://github.com/pebble/pebblejs/)

Program the Pebble with simply JavaScript

### [git-deploy](https://github.com/pebble/git-deploy/)
