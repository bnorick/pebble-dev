# PebbleKit Android Documentation

Source: https://developer.repebble.com/docs/pebblekit-android/

This is the contents page for the PebbleKit Android SDK documentation, which includes all information on the two main packages below:

### [com.getpebble.android.kit](/docs/pebblekit-android/com/getpebble/android/kit.md)

### [com.getpebble.android.kit.util](/docs/pebblekit-android/com/getpebble/android/kit/util.md)

This part of the SDK can be used to build companion apps for Android to enhance the features of the watchapp or to integrate Pebble into an existing mobile app experience.

Get started using PebbleKit Android by working through the[_Android Tutorial_](/tutorials/android-tutorial/part1). Check out[_PebbleKit Android_](/guides/communication/using-pebblekit-android.md) to learn more about using this SDK.

You can also find the source code for PebbleKit Android[on GitHub](https://github.com/pebble/pebble-android-sdk).
