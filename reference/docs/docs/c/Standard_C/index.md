# Standard C

Source: https://developer.repebble.com/docs/c/Standard_C/index.html

Standard C types, functions, constants, etc.

The standard C functions available here, such as [snprintf()](/docs/c/Standard_C/Format/#snprintf) and [time()](/docs/c/Standard_C/Time/#time), are provided by the firmware. Using these functions will not significantly increase the size of your app beyond what is needed to call the function. You may use other standard C functions not listed here, but be aware that not all will successfully be added to your app, and if they are added, your app's binary size will increase accordingly.
